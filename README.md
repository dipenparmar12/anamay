# Anāmay Ashram: offline archive and website redesign

This folder holds three things:

| Folder | What it is |
|---|---|
| `offline-site/` | A complete offline copy of https://anamayashram.org as crawled on 3 Nov 2026: 107 pages and 1,036 images, stylesheets, fonts, scripts and PDFs (311 MB). Links point to the local copies. `offline-site/_all-pages.html` lists every page. |
| `content/` | What the old site says. `SITE-AUDIT.md` summarises the organisation, its offerings and contact details, lists the theme-demo leftover pages and records what is broken on the live site. `RESEARCH.md` lists the external facts used in the redesign and their sources. `pages/*.md` holds the extracted text and images of every page. `videos.json` lists all YouTube videos with titles. |
| `website/` | The redesigned site: 22 static pages, no framework, works offline. |

## Viewing

Both sites are best viewed through the small local server (Node.js 18 or later):

```bash
node serve.mjs website 8080
```

```bash
node serve.mjs offline-site 8081
```

Then open http://localhost:8080 for the redesign and http://localhost:8081 for the old site.

You can also double-click `website/index.html` and it will work. Chrome does not load web fonts from `file://`, though, so the pages fall back to system fonts.

## The redesign at a glance

- **Identity:** a parchment, saffron, turmeric-gold and indigo-night palette drawn from temple murals and Pichwai painting. Type is Cormorant Garamond for headings, Mukta for body text and Tiro Devanagari Sanskrit for Sanskrit. All fonts are self-hosted. Ornaments include a generated mandala, temple-doorway (ogee) arches around photos, a lotus divider, a kolam dot grid, paper grain and Himalayan ridge lines.
- **Motion:** content fades up gently on scroll, images reveal with a soft curtain, the hero has slow parallax, the mandala turns once every four minutes, a strip of Sanskrit verses drifts by, and a breathing orb sits on the meditation pages. Pages fade between each other. All motion turns off for visitors who choose reduced motion in their system settings.
- **Structure:** Home · About (The Ashram, Founder) · Vedic Knowledge (Vedas, Vidyapeeth, Yagya & Jyotish) · Wellbeing (Meditation, Yoga, Āyurveda, Panchakarma, Kshar Sutra) · Ashram Life (Sattvic Life, Volunteer & 1-week course, Gallery, Journal & Magazine) · Contribute · Visit & Contact. Also three articles, policies and image credits.
- **Forms:** the enquiry form checks the fields, then opens the visitor's own email app or WhatsApp with the message ready to send. No server is needed. Donations link to the existing donation page on anamayashram.org.
- **Images:** 52 of the ashram's own photographs, plus 23 openly licensed photographs from Wikimedia Commons. Every one of those is credited on `credits.html` and next to the image.

## Editing and rebuilding

Each page's content lives in `website/src/pages/*.html`. The shared header, footer, navigation, icons and ornaments are generated by `website/src/build.mjs`. After editing, run:

```bash
cd website && npm install && npm run build
```

`npm run images` re-creates the resized photographs from `offline-site/`. `node src/fetch-external.mjs` re-downloads the licensed images listed in `src/credits.json`.
